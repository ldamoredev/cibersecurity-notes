# Atlas Security Range

Atlas Security Range es el proyecto local y determinista que conecta mapa de
activos, modelo de amenazas, fixture vulnerable, telemetría, detección,
contención, fix y prueba de regresión. Los hitos v0–v11 están en
`LABS-ROADMAP.md`.

## Límite de autorización

Ejecutalo solo contra fixtures locales o sistemas propios con autorización
explícita. No hay exposición pública, credenciales reales, datos personales ni
escaneo de terceros.

## Resultado esperado

Cada ejercicio debe producir evidencia estructurada, un control probado y una
ruta de reset.
