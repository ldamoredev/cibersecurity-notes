# Atlas Security Range

Atlas Security Range is the local, deterministic project that connects an
asset map and threat model to a vulnerable fixture, telemetry, detection,
containment, fix, and regression test. It is planned in milestones v0–v11;
read `LABS-ROADMAP.md` for the sequence and safety boundary.

## Authorization boundary

Run only against local fixtures or systems you own and explicitly authorize.
No public exposure, real credentials, personal data, or third-party scanning.

## Expected output

Each exercise will produce a documented state transition, structured evidence,
a tested control, and a reset path. A lab without those artifacts is not part
of the Range.
