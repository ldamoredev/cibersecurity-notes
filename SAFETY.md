# Safety and authorization

Cybersecurity Atlas is for understanding systems and improving controls. Any
hands-on material is limited to local fixtures, CTFs, deliberately vulnerable
applications, testnets, and systems for which the operator has explicit
authorization.

Never use this repository to scan third parties, collect personal data, steal
credentials or sessions, deploy vulnerable public services, evade a real
organization, or automate indiscriminate attacks. A lab must state its scope,
fixture, expected result, telemetry, fix, regression test, and reset path.

`local-only` is a release boundary: content and validation treat it as an
authorization claim, not as a disclaimer that permits broader use.
